# 408 考研笔记规范（薄弱点速记版）

## 笔记定位

只记**不会的、混淆的、记不住的**，会的知识点一律不写。
笔记用于**打印出来快速翻阅**，不是替代教材。

## 1. 文件结构（沿用现有）

```
计组/
├── 第一章概述.md
├── 第三章存储器.md
├── 第四章 指令系统.md
└── 第五章CPU.md
```

每科一个文件或按章拆分均可，怎么方便怎么来。

## 2. 每个知识点的格式

### 标准条目

```markdown
### 知识点名 [标记]

一句话总结/关键结论。$公式$

**坑点**：==容易错的地方==。
```

### 纯截图条目（快速记录用）

```markdown
### 知识点名 [标记]

![[截图.png]]
```

**改进建议**：即使只加 5 个字也比纯截图好：
```markdown
### 知识点名 [标记]

结论：xxxxx
![[截图.png]]
```

## 3. 知识点标记

```
[记]  → 记住了但容易忘
[混]  → 容易跟别的概念搞混
[坑]  → 有陷阱/易错
[难]  → 理解困难
[计]  → 计算题相关
```

## 4. 排版要点（面向打印）

- 多留空行，方便手写补充
- 表格尽量简洁，一页能看完
- 重点用 `==高亮==` 标记（Obsidian 导出打印时仍保留）
- 一页一个主题，不要太长

## 5. 示例（你第四章的写法就很好）

```markdown
# 4.数据通路

### 单总线 ADD 指令 [难]

**背景**：ALU 两个输入端不能同时从总线拿数据，必须用 Y、Z 暂存。

| 节拍 | 微操作 | 关键信号 |
|------|--------|----------|
| C1 | (PC)→MAR | PCout, MARin |
| C2 | Mem[MAR]→MDR, PC+1 | MemR, MDRinE, PC+1 |
| ... | ... | ... |

**坑点**：==同一拍不能有两个 xxxout==。
```
